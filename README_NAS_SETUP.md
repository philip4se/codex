## 🔧 NAS 백업 설정

### Step 1: NAS WebDAV 활성화

1. **Synology NAS 관리 페이지 접속**
   ```
   http://192.168.0.26:5000
   ```

2. **제어판 → 파일 서비스**

3. **WebDAV 설정**
   ```
   ☑️ WebDAV 활성화 (HTTP)
   HTTP 포트: 5005

   ☑️ WebDAV 활성화 (HTTPS) - 권장
   HTTPS 포트: 5006
   ```

4. **적용 클릭**

### Step 2: WebDAV 폴더 생성

1. **File Station 열기**

2. **폴더 생성**
   ```
   경로: /web/webdav/facility-backup/
   권한: admin 계정에 읽기/쓰기 권한 부여
   ```

### Step 3: check1.html에서 NAS 설정

1. **"백업" 탭으로 이동**

2. **NAS 서버 설정 입력**
   ```
   NAS URL: http://192.168.0.26:5005/webdav/facility-backup/
   사용자명: admin
   비밀번호: [NAS 관리자 비밀번호]
   ```

3. **"연결 테스트" 클릭**

4. **성공 메시지 확인**
   ```
   ✅ NAS 연결 성공! WebDAV 서버에 접근할 수 있습니다.
   ```

5. **자동 백업 활성화**
   ```
   ☑️ 중앙 서버 백업 활성화
   백업 주기: 매일
   ```

## 🌐 CORS 문제 해결

NAS 백업을 사용하려면 브라우저 CORS 정책을 해결해야 합니다.

### 방법 1: 브라우저 확장 프로그램 (가장 쉬움) ⭐

#### **Chrome/Edge 사용자:**

1. **Chrome 웹 스토어 접속**
   ```
   https://chrome.google.com/webstore/
   ```

2. **"Allow CORS" 검색**

3. **"Allow CORS: Access-Control-Allow-Origin" 설치**
   - 제작자: vitvad
   - 빨간색 방패 아이콘

4. **확장 프로그램 활성화**
   - 브라우저 오른쪽 위 퍼즐 아이콘 클릭
   - "Allow CORS" 찾기
   - 토글을 **ON**으로 변경 (파란색/초록색)

5. **check1.html 새로고침 (F5)**

6. **NAS 연결 테스트**

⚠️ **주의:** 일반 웹 서핑 시에는 확장 프로그램을 꺼두세요!

---

### 방법 2: Python 웹 서버 사용 (권장)

#### **Mac 사용자:**

1. **터미널 열기**

2. **check1.html 폴더로 이동**
   ```bash
   cd /경로/to/codex
   ```

3. **웹 서버 시작**
   ```bash
   python3 -m http.server 8000
   ```

4. **브라우저에서 접속**
   ```
   http://localhost:8000/check1.html
   ```

#### **Windows 사용자:**

1. **명령 프롬프트 (cmd) 열기**

2. **check1.html 폴더로 이동**
   ```cmd
   cd C:\경로\to\codex
   ```

3. **웹 서버 시작**
   ```cmd
   python -m http.server 8000
   ```

4. **브라우저에서 접속**
   ```
   http://localhost:8000/check1.html
   ```

## ☕ 음료 주문 시스템 사용법

### 회원 모드 (비관리자)

1. **"음료 주문" 탭 클릭**

2. **음료 선택**
   - 음료 카드를 클릭하여 상세 정보 확인
   - 설명 확인

3. **"주문하기" 버튼 클릭**

4. **회원 검색**
   - 이름, 생년월일, 연락처, 회원번호로 검색

5. **검색 결과에서 "주문" 버튼 클릭**
   - 주문 가능: 파란색 "주문" 버튼
   - 주문 불가능: 회색 "불가능" 버튼 (1일 1잔 이미 사용)

6. **주문 확인 모달**
   - 회원명과 음료명 확인
   - "확인" 클릭

7. **주문 성공 알림**
   ```
   ✅ 정상 주문 완료
   ```

### 관리자 모드

1. **우측 상단 "관리자 모드" 토글 켜기**

2. **"음료 주문" 탭 클릭**

3. **대기 중인 주문 확인**
   - 주문 순서대로 표시
   - 음료명과 주문자명(노란색) 표시

4. **음료명 클릭**
   - 제조 방법 (재료 및 레시피) 확인

5. **"완료" 버튼 클릭**
   - 주문이 목록에서 사라짐
   - 자동으로 통계에 반영

## 🔧 문제 해결

### Q1. "ERR_NAME_NOT_RESOLVED" 오류

**원인:** NAS IP 주소가 잘못되었습니다.

**해결:**
1. NAS 관리 페이지에서 실제 IP 주소 확인
2. 올바른 IP 주소로 변경
   ```
   예: http://192.168.0.26:5005/webdav/facility-backup/
   ```

---

### Q2. "CORS policy" 오류

**원인:** 브라우저 보안 정책

**해결:**
- 방법 1: Allow CORS 확장 프로그램 설치 및 활성화
- 방법 2: Python 웹 서버 사용
- 방법 3: VS Code Live Server 사용

---

### Q3. "인증 실패" 또는 "401 Unauthorized"

**원인:** 잘못된 사용자명 또는 비밀번호

**해결:**
1. NAS 로그인 정보 확인
2. WebDAV 활성화 확인
3. 사용자 권한 확인 (제어판 → 사용자)

---

### Q4. "InvalidCharacterError: btoa" 오류

**원인:** 이 오류는 이미 수정되었습니다!

**현재 상태:**
- ✅ 한글 사용자명/비밀번호 완벽 지원
- ✅ 모든 특수문자 지원

---

### Q5. 관리자 모드에서 완료 버튼이 작동하지 않음

**원인:** 이 문제는 이미 해결되었습니다!

**현재 상태:**
- ✅ 완료 버튼 클릭 시 주문이 즉시 목록에서 사라짐
- ✅ 자동으로 통계에 반영됨

---

### Q6. 비관리자 모드에서 주문 확인 버튼 클릭 시 반응 없음

**원인:** 이 문제는 이미 해결되었습니다!

**현재 상태:**
- ✅ 첫 번째 클릭에서 "정상 주문 완료" 알림 표시
- ✅ DOM 타이밍 문제 해결됨

## 📊 IP 주소 가이드

### 내부 IP (로컬 네트워크) - 기본 사용

**형식:**
```
192.168.x.x
10.x.x.x
172.16.x.x ~ 172.31.x.x
```

**사용 시기:**
- ✅ 같은 건물/사무실/집 안에서 사용
- ✅ 같은 와이파이에 연결되어 있을 때

**찾는 방법:**
- NAS 관리 페이지 → 제어판 → 네트워크
- 공유기 관리 페이지 → 연결된 기기 목록

---

### 외부 IP (공인 IP) - 외부 접속 시

**사용 시기:**
- ✅ 외부 (다른 건물, 카페, 타 기관)에서 접속

**필요한 설정:**
1. 공유기 포트 포워딩
2. DDNS 또는 고정 IP
3. SSL 인증서 (보안)
4. 방화벽 설정

⚠️ **현재는 내부 네트워크에서만 사용하시므로 필요 없습니다!**
