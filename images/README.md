## 이미지 권장 사양
- **크기**: 64x64 픽셀 (또는 128x128)
- **포맷**: PNG (투명 배경 권장)
- **스타일**: 도트 아트, RPG 캐릭터 스타일
- **전직별 차별화**: 단계가 높아질수록 더 화려하고 강해 보이게!

## 이미지가 없을 경우
이미지 파일이 없으면 자동으로 직업 아이콘(이모지)이 표시됩니다.

## 전직 단계별 효과
- **0차 (기본)**: 회색 테두리
- **1차**: 초록색 발광
- **2차**: 파란색 발광
- **3차**: 보라색 발광
- **4차**: 황금색 발광 (가장 화려!)
